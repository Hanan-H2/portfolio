# Hanan Hussein Portfolio

A responsive personal portfolio website for showcasing Hanan's background, web development skills, projects, and contact information.

## Sections

- About
- What I Do and Technical Skills
- Portfolio projects: AI Forum, ChatGPT Clone, and Netflix Clone
- Resume
- Contact form

## Run locally

The site is built with HTML, CSS, and JavaScript; no Node.js build step is required. To preview the site, open `index.html` in a browser or serve the project directory with a local static web server.

The contact form uses JavaScript to validate the fields, open a prefilled message in the visitor's default email app, and clear the form. The visitor must send the draft from that app; the static site cannot confirm email delivery.

## Project structure

- `index.html` — page content and section layout
- `css/` — Bootstrap, vendor, theme, and custom styles
- `js/` — site scripts
- `images/` — portfolio, project preview, and theme images
